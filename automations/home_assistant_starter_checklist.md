# Home Assistant Einsteiger-Checkliste

Schritt-für-Schritt von 0 zum laufenden Smart Home.

Alle verlinkten Anleitungen auf **https://smarthome-praxis.de**

---

## Phase 1: Hardware & Installation

- [ ] Raspberry Pi 5 besorgen (4 GB RAM empfohlen)
- [ ] Home Assistant OS installieren → [Anleitung](https://smarthome-praxis.de/home-assistant-raspberry-pi-installieren/)
- [ ] Zigbee-Koordinator anschließen (z.B. SONOFF ZBDongle-P) → [Vergleich](https://smarthome-praxis.de/beste-zigbee-koordinatoren-2026/)

## Phase 2: Zigbee einrichten

- [ ] Zigbee2MQTT oder ZHA wählen → [Vergleich ZHA vs Z2M](https://smarthome-praxis.de/zha-vs-zigbee2mqtt/)
- [ ] Zigbee2MQTT Add-On installieren → [Anleitung](https://smarthome-praxis.de/zigbee2mqtt-einrichten/)
- [ ] Erste Geräte pairen (Steckdosen, Sensoren, Lampen)

## Phase 3: Erste Automationen

- [ ] Anwesenheitserkennung einrichten
- [ ] Beleuchtungsautomation per Bewegungsmelder
- [ ] Heizung optimieren → [Anleitung](https://smarthome-praxis.de/heizung-home-assistant-thermostat/)
- [ ] Automationen erstellen lernen → [Guide](https://smarthome-praxis.de/home-assistant-automationen-erstellen/)

## Phase 4: Erweitern

- [ ] Node-RED für komplexe Automationen → [Anleitung](https://smarthome-praxis.de/node-red-home-assistant/)
- [ ] Matter & Thread-Geräte einbinden → [Guide 2026](https://smarthome-praxis.de/matter-thread-smart-home/)
- [ ] Smart Home absichern (VPN, Updates) → [Sicherheits-Guide](https://smarthome-praxis.de/smart-home-absichern-sicherheit/)
- [ ] NAS / Heimserver aufbauen → [Anleitung](https://smarthome-praxis.de/raspberry-pi-heimserver-nas/)
